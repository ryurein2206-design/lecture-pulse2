GitHub Pages / Netlify での動作＆データベース設定

設定不要でそのまま複数人リアルタイム同期が動きます！

このバージョンでは、GitHub Pages や Netlify に index.html をそのままアップロードした際、Firebase の設定がまだ無くても自動的に公開WebSocketリレー（MQTT over WSS）およびタブ間通信へ接続し、スマホ・PC間でリアルタイムにリアクションとコメントが共有されます。

オプション: 専用 Firebase Firestore を使う場合

永続的に講義データをクラウド保存したい場合は、Firebase Console で作成した firebaseConfig を以下に貼り付けるか、コード内の CUSTOM_FIREBASE_CONFIG に設定してください。
